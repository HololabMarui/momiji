# もみじ台 いいな投票サイト 設定手順

## フォルダの中身

| ファイル | 役割 |
| --- | --- |
| index.html / style.css / app.js | 投票サイト本体（iPad用） |
| data.js | 画像の説明・ペルソナ・設定。**文面の修正と GAS の URL 設定はここだけ** |
| monitor.html | 結果モニター（運営用。会場のPCやモニターで開く） |
| sw.js | 回線が切れても表示できるようにするキャッシュ |
| img/ | 画像（一覧用 _s / 詳細用 _l の WebP） |
| gas/Code.gs | 集計用スクリプト（GitHub には上げなくてよい） |

## 1. スプレッドシートと集計スクリプト（約20分）

1. ホロラボの Google ドライブで新しいスプレッドシートを作る（例：「もみじ台いいな投票_集計」）
2. メニュー「拡張機能 > Apps Script」を開き、最初からある中身を消して `gas/Code.gs` を丸ごと貼り付けて保存
3. 関数の選択で `setup` を選んで「実行」。初回は権限の確認が出るので許可する
   → `votes` `images` `集計` の3つのシートができる
4. 右上の「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された「ウェブアプリ URL」（`https://script.google.com/macros/s/…/exec`）をコピー
6. `data.js` の `GAS_URL: ""` の中に貼る

> **注意**：手順4で「全員」が選べず「ホロラボ内の全員」しか出ない場合は、Workspace 管理者の設定で外部公開が止められています。そのままだと会場の iPad から送信できないため、管理者に許可してもらうか、個人の Google アカウントで作り直してください。

> Code.gs を修正したときは「デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン：新バージョン」で更新すると URL が変わりません。

## 2. GitHub Pages に公開（約10分）

1. GitHub で新しいリポジトリを作る（公開範囲 Public。URL は来場者に案内しないので検索には出にくい）
2. `gas` フォルダ以外の一式をアップロード
3. Settings > Pages > Branch を `main` / `(root)` にして Save
4. 数分後、`https://<アカウント>.github.io/<リポジトリ名>/` で開ける
   - 結果モニター：`…/monitor.html`

## 3. iPad の準備（1台5分程度 × 5台）

1. Safari で `…/index.html?device=iPad1` を開く（2台目は `iPad2` …。端末名がスプレッドシートに記録されます）
2. 共有ボタン →「ホーム画面に追加」→ ホーム画面のアイコンから開く（アドレスバーのない全画面になる）
3. 設定 > 画面表示と明るさ > 自動ロック：**なし**
4. 画面の向きを横でロック
5. 設定 > アクセシビリティ > アクセスガイダンス を ON → アプリを開いてホームボタン（またはトップボタン）を3回押して開始。来場者がアプリから出られなくなります

## 4. 当日の運用

- **テスト投票の削除**：本番前に `votes` シートのテスト行を消し、`集計` を更新するため Apps Script で `setup` をもう一度実行
- **スタッフメニュー**：投票画面の左上タイトルを **3秒長押し** → 未送信件数の確認・再送・この端末の投票の CSV 保存
- 回線が切れても投票は iPad 内にたまり、つながると 20秒ごとに自動で再送されます（同じ投票が二重に記録されることはありません）
- 無操作 60秒で最初の画面に戻ります（`data.js` の `IDLE_SECONDS` で変更可）

## テストモード

`GAS_URL` が空のままだと、投票はその端末の中だけに保存されます（集計表示・結果モニターも同じ端末内の票で動きます）。画面の確認だけしたいときに使えます。

## 文面・画像を直したいとき

- 説明文やタイトル：`data.js` を書き換えてアップロード（Code.gs の IMAGES のタイトルも合わせると集計シートが揃います）
- 画像を差し替えたら `sw.js` の `VERSION` を `v2` などに上げてアップロード（iPad に古い画像が残らないように）
